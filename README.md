# 🧱 Ironexa – Iron Fabrication Management System

A full-stack web application to manage iron fabrication orders, customers, and payments.

---

## 🚀 Live Demo

🔗 Frontend: Coming Soon
🔗 Backend API: Coming Soon

---

## 📌 Features

* 📦 Create & Manage Orders
* ✏️ Edit Orders (dynamic product handling)
* 🖼️ Image Upload
* 💰 Payment tracking
* 📊 Dashboard with analytics
* 🔍 Order status tracking

---

## 🛠️ Tech Stack

### Frontend

* React
* Tailwind CSS
* Axios

### Backend

* .NET 6 Web API
* Entity Framework Core

### Database

* SQL Server

## ⚙️ Setup Instructions

### Backend

```id="2"
cd backend
dotnet restore
dotnet run
```

### Frontend

```id="3"
cd frontend
npm install
npm run dev
```
